## 2. 반응형 뷰포트 검증 기준

1. **Mobile Portrait (375 × 812)**:
   - 가로 스크롤(Horizontal Overflow) 발생 0px
   - 모바일 햄버거 토글 버튼 터치 영역 44px 이상
   - 드로어 메뉴 정상 동작 및 스크롤 락 확인
2. **Tablet Portrait (768 × 1024)**:
   - 가로 메뉴 정렬 및 Hero 영역 적정 비율 확인
   - 콘텐츠 카드 2열 그리드 배치 확인
   - 갤러리 2열 그리드 배치 확인
3. **Desktop (1280 × 800 & 1440 × 900)**:
   - 최대 폭 제약 및 중앙 정렬 유지
   - 갤러리 4열 수평 파노라마 배치 확인
   - Sticky Header 블러 효과 및 호버 마이크로 인터랙션 확인

## 3. Playwright E2E 시나리오 목록

1. **시나리오 1: 홈 렌더링 및 콘텐츠 불변성 검증**
   - 페이지 진입 시 로고, 4대 메뉴, Hero, 2대 카드, 4대 갤러리, 푸터 텍스트가 모두 렌더링되는가?
2. **시나리오 2: 라이트박스(Lightbox) 인터랙션 및 키보드 제어**
   - 갤러리 이미지 클릭 시 모달이 정상적으로 열리는가?
   - 화살표 키(ArrowRight, ArrowLeft)로 이미지 전환이 되는가?
   - ESC 키 입력 시 모달이 닫히고 원래 트리거 요소로 포커스가 복귀하는가?
3. **시나리오 3: 모바일 네비게이션 드로어**
   - 모바일 화면(375px)에서 햄버거 버튼 클릭 시 메뉴가 열리는가?
   - 링크 클릭 또는 ESC 키 시 메뉴가 닫히는가?
4. **시나리오 4: Hero 및 Card 'Read More' 상세 뷰어**
   - 버튼 클릭 시 실제 연동된 상세 모달이 열리고 정보가 제공되는가?
5. **시나리오 5: 관리자 로그인 및 보안 제어**
   - 미인증 상태에서 관리자 API 접근 시 401 Unauthorized 반환하는가?
   - 올바른 자격증명으로 로그인 시 세션 쿠키가 발급되는가?

## 4. 합격 판정 기준 (Acceptance Criteria)

- 모든 Vitest 단위/통합 테스트 100% 통과 (Pass)
- Playwright E2E 테스트 100% 통과 (Pass)
- axe-core Critical / Serious 접근성 위반 0건
- 브라우저 콘솔 에러 및 네트워크 404/500 에러 0건
- 원본 콘텐츠와 렌더링 콘텐츠 불일치 0건
